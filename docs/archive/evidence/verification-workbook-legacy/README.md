# Legacy reference workbook (superseded)

Superseded on 2026-10-20 by DEC-011 (strict cash) and DEC-012 (single Mankeu template).

This case study (Dapur Sambal Nusantara) uses the retired five-sheet reference format and contains
credit sales, payables, a loan and interest, none of which Mankeu imports or models any more. It is
kept as historical evidence of the earlier reconciliation work only. The generator script here
still writes to its old paths and is not maintained.

The template-format end-to-end checks are `TemplateImportTest` (unit) and `ImportCommitTest`
(instrumented). Regenerating a strict-cash case study in template format is tracked in
`docs/audit/2026-10-20_RENCANA_PERBAIKAN.md`.
